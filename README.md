# Retail-Sales-Data-Analysis
Retail Sales Exploratory Data Analysis (EDA)

Project Overview

This project was completed as Task 1 of my Oasis Infobyte internship. The objective was to explore retail sales data, understand customer behaviour, identify sales trends, and generate actionable business insights.

Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

Key Analysis

- Data inspection and quality checks
- Descriptive statistical analysis
- Monthly and quarterly sales trends
- Customer age and gender distribution
- Top 10 best-selling products
- Revenue analysis by product category
- Correlation heatmap
- Additional visualisation to identify business patterns

Key Outcomes

Explored retail sales patterns, customer demographics, and product performance to identify potential business opportunities and formulate data-driven recommendations.

Project Files

- "Retail_Sales_EDA.ipynb" — Jupyter Notebook containing the analysis, visualisations, and observations.
- "retail_sales_dataset.csv" — Dataset, if redistribution is permitted.

How to Run

1. Clone or download this repository.
2. Install the required libraries:
 "pip install pandas numpy matplotlib seaborn jupyter"
3. Open the notebook in Jupyter Notebook.
4. Update the dataset file path if required and run the cells.
